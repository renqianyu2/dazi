# 拼音打字速度测试系统

一个面向小学生的拼音打字练习和测试系统，支持实时统计、排行榜、成绩管理等功能。

## 功能特点

- ⌨️ 拼音打字速度测试（60秒）
- 🎮 多种练习模式（开发中）
- 📊 实时数据统计和排行榜
- 🏆 成绩达标判定
- 👨‍🏫 教师管理后台
- 📝 自定义文本库

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 初始化数据库

```bash
npm run init-db
```

### 3. 启动服务器

```bash
npm start
```

服务器将在 `http://localhost:3000` 启动

### 4. 访问系统

**学生端：**
- 本机访问：http://localhost:3000
- 局域网访问：http://你的IP地址:3000

**管理端：**
- 访问：http://localhost:3000/admin/login.html
- 默认账号：admin
- 默认密码：admin123

## 微机室部署

1. 选择一台电脑作为服务器
2. 在该电脑上运行 `npm start`
3. 查看该电脑的局域网IP地址（如 192.168.1.100）
4. 其他电脑通过浏览器访问：http://192.168.1.100:3000


## 测试规则

- 测试时间：60秒
- 达标标准：速度 ≥ 30字/分 且 准确率 ≥ 85%
- 连续错误5次自动结束，成绩无效
- 不允许修改已输入内容（禁用退格键）

## 技术栈

- 后端：Node.js + Express + SQLite
- 前端：原生 HTML/CSS/JavaScript
- 拼音处理：pinyin-pro
